## 🆕 Novedades de la versión 2.0

En esta nueva versión he incorporado varias mejoras orientadas a aumentar la seguridad y facilitar el uso de la aplicación:

- **Confirmación de cálculo:** ahora, antes de realizar un cálculo, la aplicación muestra los cuatro valores introducidos y solicita confirmación para evitar cálculos con datos incorrectos.
- **Confirmación de restablecimiento:** antes de borrar los datos introducidos, la aplicación solicita confirmación para evitar eliminaciones accidentales.
- **Botón «Volver»:** se ha añadido una función de recuperación que permite restaurar los últimos datos y resultados calculados en caso de haberlos restablecido accidentalmente. Una vez recuperados, el botón desaparece automáticamente.

Estas mejoras buscan reducir errores durante el uso de la aplicación y ofrecer una mayor seguridad al trabajar con los cálculos.
